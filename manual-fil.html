1.3 Pagdaragdag ng Customer at Pag-apply ng Diskwento
👤 Pagdaragdag ng Customer
1
I-tap ang "Add Customer"
Makikita ito sa itaas ng Order Summary panel.
2
Maghanap o Gumawa ng Bago
I-type ang numero o pangalan ng customer para hanapin siya. Kung bago, i-tap ang Create New Customer.
3
Punan ang Detalye
Ang first name ay kailangan. Ang last name at phone number ay opsyonal ngunit makakatulong para sa susunod na paghahanap.
⚠️
Paalala Kung mayroon nang account ang customer, maghanap muna para maiwasan ang pagdodoble ng record.
💰 Pag-apply ng Diskwento
1
I-tap ang "Discount"
Makikita ito sa ibabang bahagi ng Order Summary.
2
Piliin ang Uri ng Diskwento
Pumili ng Peso Amount (hal. ₱50 off) o Percentage (hal. 10% off).
3
Ilagay ang Halaga at I-confirm
Makikita ang diskwento sa Order Summary at ibabawas sa kabuuan.
⚠️
Babala Hindi na mababago ang diskwento pagkatapos i-place ang order. I-double check bago pindutin ang Place Order.

3.2 Pamamahala ng Orders at Pag-assign ng Driver

Mula sa Admin Orders page, makikita ninyo ang lahat ng orders sa bawat branch at maaari kayong mag-assign ng driver para sa delivery.

📋 Pagtingin ng mga Order
  • Pumunta sa Orders sa sidebar
  • Ipinapakita ang lahat ng orders mula sa lahat ng branches sa iisang listahan
  • Mag-filter sa status: All, Pending, Confirmed, Processing, Ready, Completed, Cancelled
  • Mag-click ng anumang order row para buksan ang Order Detail Panel sa kanan
  • Ipinapakita ng Order Detail ang: lahat ng items, impormasyon ng customer, branch, history ng status, at assignment ng driver
🚗 Pag-assign ng Driver
1
Buksan ang Order Detail
Mag-click ng order mula sa listahan ng Orders. Bubuksan ang detail panel sa kanang bahagi.
2
Hanapin ang "Assign Driver" Button
Ang button na ito ay lumalabas para sa mga order na may status: Confirmed, Processing, Ready, o Out for Delivery.
3
Pumili ng Driver mula sa Dropdown
Ipinapakita ng dropdown ang mga driver na available sa branch. Piliin ang driver.
4
I-tap ang "Assign"
Na-assign na ang order. Makikita ng driver ito sa kanilang Driver App na may BAGO badge.
